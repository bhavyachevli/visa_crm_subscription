# Pangaea Pathways CRM

This is the rebuilt CRM for Pangaea Pathways based on the provided master prompt.

## Stack
- Frontend: React (Vite) + Tailwind CSS
- Backend: Python (FastAPI)
- Database: MongoDB (PyMongo)

## Setup
### Backend
```sh
cd server
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Frontend
```sh
cd client
npm install
npm run dev
```
